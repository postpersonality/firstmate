# Выбор папки запуска агента

**Цель:** в «Новый агент» можно вставить путь или выбрать недавнюю папку; запуск идёт в выбранной папке, отдельная копия Git включается явно.

**Устройство:** полный путь хранится в привязке сессии, домашний префикс показывается как `~`. Недавние исходные папки сохраняются в существующем кэше. Для рабочей копии сохраняются исходная и фактическая папки; выбранная подпапка репозитория сохраняется внутри копии. Общая папка с несколькими репозиториями остаётся обычной рабочей папкой.

**Технологии:** существующие TypeScript, Node.js, HTML datalist, Git worktree. Новых зависимостей нет.
