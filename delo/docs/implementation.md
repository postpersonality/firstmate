# MVP «Дела»

Источник требований — приложенная концепция. Реализация охватывает программную часть трёх этапов «Папка дела», «Карта», «Архив». Неделя работы с 3–5 реальными целями — пользовательская проверка пользы после технической проверки.

Node.js 24 и TypeScript; встроенные HTTP и SQLite FTS5; YAML для дополнений; официальный MCP SDK. Firstmate хранит название, тело и базовое состояние целей, а `.data` хранит области, пространство, обложку, ссылки, историю, знания и кэш. Интерфейс работает в браузере; агентам доступны CLI, Firstmate и MCP. Подключения агентов объявляют возможности явно.

- [x] Файлы: создание цели, три строки обложки, бриф, привязки, журнал только с добавлением, знания. Проверить запрет повторной привязки сессии, закрытую цель и приоритет ручной обложки.
- [x] Поиск: индекс из файлов обоих хранилищ, включая закрытые цели; пересоздание после удаления; компактная ориентировка с оглавлением знаний.
- [x] Агенты: Claude Code и Codex, отдельные worktree и вкладки herdr, MCP, сигналы, возобновление, рапорт и автоматическая запись из журнала при отсутствии рапорта.
- [x] Карта: области, состояния, сигналы, новые рапорты, «Неразобранное», ручные привязки, редактирование брифа и обложки, знания и запрос выжимки статьи.
- [x] Jira: только чтение через CLI навыка Jira, без собственного сетевого запроса и без чтения токена. Git и PR — через локальные git/gh, без записи во внешний трекер.
- [x] CLI и обработчик `delo://session/<id>`: ссылка на `../herdr-focus` как пример реализации фокуса окна и панели; использование `herdr-jump://`.
- [x] Проверка: файловые и доменные сценарии, реальный обмен MCP, запуск CLI с тестовым агентом, HTTP-обработчик, интерфейс, сборка и проверка типов. Отдельно указать непроверенные интеграции рабочего стола и внешних сервисов.

Исходные вложения сохраняются без изменений. Коммиты, установка обработчика в домашний каталог и запуск платных агентов не входят в технические проверки.
